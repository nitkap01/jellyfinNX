JellyfinFlix for iPhone: screen designs

Same look as JellyfinFlix on the TV (black, red accent, white rounded buttons), reshaped for a phone: tall screens for browsing, sideways for watching. Pictures load live from the home Jellyfin server.

Frames are iPhone 15/16 size (390 x 844 points). The player turns sideways on its own. Fix Audio and Fetch Subtitle use the same server helper the TV uses and only show for admin profiles.
